Tools

Engineering tools I built

Two piping calculation tools that run entirely in the browser — open them right here, nothing to install. Both ship a self-verification that checks the solver against closed-form solutions.

Pipe wall thickness

ASME B31.3 · B31.1 · B31.8
  • Computes t, tm, minimum order thickness and MAWP across the whole NPS range
  • Picks the lightest schedule that still passes, and handles the thick-wall branch t ≥ D₀/6
  • Screens materials by fluid and design temperature; exports a PDF calculation sheet
ASME B31.3B36.10M JavaScriptno dependencies
Open tool Full screen Source

Pipe support analysis

2D frame finite elements
  • Euler–Bernoulli beam-column elements, 6 DOF, solving K·u = F
  • Global stability from the eigenvalue problem (K + λ·Kg)·φ = 0
  • Member checks to AISC 360, and auto-sizing to the lightest section that passes
FEMAISC 360 JavaScriptno dependencies
Open tool Full screen Source

Both are screening and preliminary-sizing tools — they do not replace review by a qualified engineer.
